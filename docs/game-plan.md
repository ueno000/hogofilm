# 保護フィルム貼りゲーム 企画・実装計画

## 概要

スマートフォンでURLを開いてすぐ遊べる、明るくポップな保護フィルム貼りゲームを作る。1プレイは約90秒を目安とし、結果は「点数の軸3つ」と「やらかしの軸3つ」で評価する（詳しくは「評価」）。

## ゲームの流れ

操作を次の5工程に分ける。

1. **ウェットシートで拭く** — 画面上をドラッグして拭き取る。汚れは場所によって1〜3段あり、しつこい汚れは何度かこすらないと落ちない。汚れが落ちた場所をさらに何度もこすると画面が削れ、基板（緑の地に回路の線）が見えてしまう。削れた分は仕上がり品質から差し引く。指（マウス）の位置には折りたたんだウェットシートの絵が出て、動かす向きに合わせて少し傾き、拭いた跡は濡れて光って少しすると乾く（見た目だけ）。指を離している間、シートは画面の横に置いておく。きれいさの割合は表示せず、拭き残しは自分の目で見て判断する（どれだけきれいになったかは結果画面で分かる）。自動では次の工程へ進まず、止めどきはプレイヤーが「次へ」で決める。
2. **埃を取る** — 丸くて白い埃取りシールで埃を取る。タップした場所にシールを押し当て、円の中にある埃をまとめて取る。押した瞬間にシールが少しつぶれ、取った埃がシールに付いて見える（見た目だけ）。PC ではカーソルの位置にシールの絵を出す。最初にいくつか置かれたあと、埃は上から1個ずつ降り続け、間隔はだんだん短くなるので取り切ることはできない。残りの埃は数字で出さず、画面に残っている数で5段階の文字を出す（20個以上＝埃まみれ（赤）、11〜19個＝埃だらけ（オレンジ）、6〜10個＝埃あり（灰色）、1〜5個＝綺麗（緑）、0個＝完璧（金色できらっと光る））。自動では次の工程へ進まず、画面の埃が0個になった瞬間（「完璧」と出る）を見極めて「貼り始める」を押す。品質は押した瞬間に残っている埃の数で決まる。
3. **位置を合わせる** — 方向ボタン（PC は矢印キー）でフィルムを動かす。短くタップすると少しだけ動き、長押しすると少し待ってから動き出して、押している間だんだん速くなる。開始時のずれは半端な量なので、押す回数を数えるだけでは合わせられない。フィルムは対角の2つの角を手で持っている絵になっていて、手が震え、汗をかいて緊張している。フィルムは手ごと小さく揺れるが、見た目だけで判定には使わない。ずれの表示や「ぴったり」の演出はなく、合っているかは結果画面で初めて分かる。品質は「決定」を押したときの本当の位置（揺れを含まない）のずれで決まる。
4. **仮固定する** — タイミングを見て4隅を順にタップする。隅をタップするたびに、判定に応じてフィルムが傾く（PERFECT は傾かない。早すぎると左回り、遅すぎると右回り。タップせずにリングが消えた MISS は遅すぎた扱い）。4隅の合計がフィルムの角度になり、傾いたまま気泡抜きの工程と結果画面の絵にも出る。品質は「1 − 角度の大きさ ÷ 許容角度」（0未満にはしない）で、早い・遅いが打ち消し合えばまっすぐに戻る。角度の数字は工程の中では表示しない。
5. **気泡を抜く** — フィルム上をドラッグして気泡を押し出す。気泡を押す指が速すぎると、気泡がちぎれて小さな気泡2つ（面積は半分ずつ）に分かれる。小さすぎる気泡はそれ以上割れない。速さの目安は表示しない。押している途中で指を離すと、フィルムの弾力で気泡が押していた向きと反対に少し戻る（画面の外に出た気泡は戻らない）。抜けた割合は表示せず、結果画面で分かる。PC ではプレイ領域の上でカーソルを指の絵にし、押している間は指先が少し沈んだ絵に変える（スマホは指で直接触るので出さない）。品質は抜けた気泡の面積の割合で、割れた気泡も面積で数え、割れたこと自体では減点しない。

仮固定で4隅の判定に大きく失敗すると、保護フィルムを床に落とす。ゲームは終わらず、残りの工程はフィルムがないまま操作なしで自動で進み（1工程あたり約1秒）、結果画面へ移る。このときやらかし「落下」がつく。その他のミスは仕上がり品質に反映する。

## 技術スタック

- **Vite＋TypeScript**で開発し、静的サイトとしてビルドする。
- **SVG／HTML／CSS**でゲーム画面と演出を描画する。操作はPointer Eventsで実装し、タッチとマウスに対応する。
- ゲーム操作領域には`touch-action`を設定し、ドラッグ中にブラウザのスクロールや拡大操作が干渉しないようにする。
- React、ゲームエンジン、物理演算ライブラリ、音声ライブラリを追加しない。効果音はブラウザ標準の Web Audio でその場で合成する（音のファイルは使わない。S-1）。
- スマートフォンはタッチ操作、PCはマウスとキーボード操作に対応する。
- 公開先は GitHub Pages（https://ueno000.github.io/hogofilm/）。`main` に入った内容を GitHub Actions（`.github/workflows/deploy.yml`）でテスト・ビルドして公開する。
- URL を SNS やメッセージに貼ったときのカード（OGP・X カード、R-12）は `index.html` に書く。画像は `public/og-card.png`（1200×630、ゲーム名とスマホにフィルムを貼る絵。元絵は `scripts/og-card.html`）、見出しは「保護フィルム貼りゲーム」、説明は「90秒で保護フィルムを貼る。拭く・埃取り・位置合わせ・仮固定・気泡抜き」。静的なサイトなので結果ごとには変えない。

## 画面とシェア

- タイトル、遊び方、工程表示、結果画面を用意する。
- 工程表示の時間ゲージは、数字を読まなくても残り時間が分かるように演出する。切り替えの時刻は制限時間に対する割合と残り秒数で決まり、制限時間を変えても動く。演出は見た目だけで、音は付けない。
  - ゲージの色は3段階。半分より前は緑、半分を過ぎたら黄色、残り10秒から赤。
  - 半分を過ぎた瞬間に、ゲージが一度ぴょんと跳ね、「半分経過！」を短く出す。
  - 残り10秒で「残り10秒！」を一度出す。そのあとはゲージと秒数が1秒ごとに脈打ち、画面の外枠がうっすら赤く点滅する。秒数の文字は赤く大きくする。
  - 合図は操作のじゃまにならないよう、HUD の中だけに出す。
- 結果画面に点数の軸3つ（段階つき）・ついたやらかし・称号とひとことを表示する。総合の品質スコアは出さない。やらかしは「やらかし：落下」のように出し、ないときは何も出さない。
- 結果画面の最初に、仕上がったスマホの絵を大きく出し、その下に点数の軸3つ・やらかし・称号を並べる。工程の中で表示を消したもの（位置のずれ・気泡など）の答え合わせになる。
  - 絵にはその回の仕上がりがそのまま出る。拭き残しはくもり、残った埃は粒、残った気泡は丸い影、位置のずれは端の段差とカメラ穴のずれ。
  - 研磨しすぎ: 削れた場所から基板（緑の地に回路の線）が透けて見える画面に、フィルムが貼られている絵。フィルムの仕上がりも重ねて出す。
  - 落下: 床に落ちて埃まみれになったフィルムと、フィルムなしのスマホを並べた絵。スマホには拭く・埃取りの仕上がりがそのまま出る。研磨しすぎも重なっていれば、基板がむき出しのスマホになる。
  - 時間切れ: 時間切れになった瞬間の状態をそのまま出す。位置合わせの前ならフィルムは画面の横に置いたまま、貼ったあとなら気泡が残ったままの絵になる。
  - 見出しは「貼り付け完了！」。フィルムを落としたまま最後まで進んだときは「フィルムなしで完走…」、時間切れのときは「時間切れ！」（落下より優先）。
  - 残り時間は独立した行にせず、手早さの点数の根拠として手早さの横に小さく添える。
- 点数の軸3つ・ついたやらかし・称号を入れた投稿文（シェア文）を作成する。
- 結果画面を開いたときに、結果を1枚の画像（PNG、1200×675 の 16:9）にしておく（R-10）。左に結果画面のスマホの絵、右に称号・ひとこと・点数の軸3つ（点数と高・中・低）・やらかし（あるときだけ）・ゲーム名と「#フィルム貼り職人」。称号が長いときは文字を小さくし、2行まで折り返す（それでも入らなければ「…」で切る）。画像の色は画面のテーマに関係なく明るいポップ調にする。
- 「シェア」ボタンを置く（R-11）。画像を共有できる端末（主にスマホ）では、端末の共有画面を開いてシェア画像とシェア文（URL つき）を渡し、送り先はプレイヤーが選ぶ。画像を共有できない端末（主に PC）では、シェア画像を保存して、続けて X の投稿画面を開く（画像はプレイヤーが自分で添付する）。共有画面を閉じた・やめたときは何も出さない。画像を作れなかったときは、X の投稿画面だけを開く。
- 「シェア」の横に「コピー」ボタンを置く。押すと、X と同じシェア文とゲームのURLをクリップボードにコピーし、「コピーしました」を短く出す。コピーできない端末では、シェア文を選択できる形で表示する。LINE や他の SNS、友だちへのメッセージにも貼り付けられるようにするため。

## 効果音

- 効果音を付ける。BGM は付けない。音はブラウザの Web Audio でその場で合成し、音のファイルも音声ライブラリも使わない（S-1）。
- iPhone では最初に画面を触るまで音を出せない。そのため最初の操作（タイトルの「スタート」など）で音の準備をする（S-1）。
- 時間ゲージの演出（U-1〜U-3）には音を付けない（S-1）。
- タイトル画面の右上と、プレイ中の HUD の右端にスピーカーのボタンを置く。押すたびに音のオンとオフを切り替える。初期値はオン。選んだ設定は次に遊ぶときも残す（localStorage）。保存を読めない環境でもオンで動く（S-2）。
- 画面のボタンを押すと短い「ポッ」が鳴る（S-3）。位置合わせの移動のボタンは「ピコッ」を鳴らすので、「ポッ」は付けない（S-6）。スピーカーのボタンは、オンにしたときだけ「ポッ」が鳴る。
- 効果音全体の音量は調整値 `SE_VOLUME`（0〜1）。

工程ごとの音（S-4〜S-9）:

| 工程 | 音 | 決まり |
|---|---|---|
| 拭く | 指の下の汚れが1段落ちたときだけ「キュッ」。一度に複数のマスが落ちても1回。続けて鳴らすときは `WIPE_SE_MIN_MS` 以上空ける | 汚れが落ちたあとの場所をこすっても鳴らない。音が止んだら「そこは綺麗」と耳で分かる（S-10。試遊の結果、S-4 の「汚れで音を変えない」から変更） |
| 埃取り | シールを押し当てるたびに「ペタッ」 | 取れても取れなくても同じ音 |
| 位置合わせ | 移動のボタン（PC の矢印キーも）を押すたびに高い「ピコッ」。長押しで動いている間は `ALIGN_SE_HOLD_MS` ごとに小さく鳴る | ぴったりかどうかでは音を変えない（A-4） |
| 仮固定 | PERFECT は高く澄んだ和音がキラッと伸びる音、GOOD は明るい短い音、BAD は鈍い音、MISS は「ブッ」。落下したときは、落ちる途中で「ガシャーン！」を一度 | 落下は笑えるよう大げさに |
| 気泡抜き | 触っている間、ぷくぷくした泡の音を鳴らし続ける（大きさは `BUBBLE_SE_VOLUME`）。指を動かしている間は大きく、止めると小さく、離すと止める。気泡が割れたとき（B-1）は「プチッ」 | 工程を抜けたら必ず止める |
| 結果画面 | 出たときに「ばばーん！」を一度。時間切れや落下のときは、少し間の抜けた「ばばーん…」 | |

音がオフのときは、どの音も鳴らない。

## 評価

仕上がりを1つの点数にまとめず、軸ごとに評価する。点数の軸は「高（80点以上）／中（40点以上）／低」の3段階に分け、称号の判定に使う。具体的な数値は企画管理シートの評価設計タブを正とする。

| 評価軸 | 種類 | 決まり方 |
|---|---|---|
| 手早さ | 0〜100点 | 残り時間が多いほど高い（一定以上残せば満点）。時間切れ・落下のときは 0 点 |
| 画面の綺麗さ | 0〜100点 | 拭く工程と埃取り工程の仕上がり（拭く工程の削れは減点に含む） |
| フィルムの貼り方 | 0〜100点 | 位置合わせ・仮固定・気泡抜きの仕上がり。落下があれば 0 点 |
| 落下 | あり／なし | 仮固定でフィルムを床に落とした |
| 研磨しすぎ | あり／なし | 拭く工程で、基板が見える場所が規定の割合を超えた。工程の中では表示しない |
| 斜め貼り | あり／なし | 仮固定で決まったフィルムの角度の大きさが規定以上。工程の中では表示しない。落下したときはフィルムを貼らないのでつかない |

## 結果一覧

結果画面とシェア文に称号とひとことを出す。称号は、あてはまる要素の言葉を全部つなげて作る（R-8）。ひとことは判定キーごとに決まる（全38種類と、埃が残ったときの単独の称号）。言葉とひとことは `src/titles.csv` から読み込み、企画管理シートの「称号CSV」タブ（新称号案タブ・称号タブ）を正とする（R-9）。

### 称号のつなげ方

並び: 手早さ → フィルムの貼り方（斜め貼りのときは「斜め貼り」の言葉）→ 気泡抜き → 研磨しすぎ → 画面の綺麗さ（最後の名詞）

| 要素 | 高 | 中 | 低 / あり |
|---|---|---|---|
| 手早さ | 早業！ | （なし） | ゆっくりで |
| フィルムの貼り方 | 1ミリの狂いもない | 平凡な | 大雑把な |
| やらかし：斜め貼り | | | 斜め貼りの申し子！（貼り方の言葉の代わり） |
| 気泡抜き | 気泡の侵入を許さない | （なし） | 気泡と同居中の |
| やらかし：研磨しすぎ | | | 基板さえも磨く |
| 画面の綺麗さ | ピカピカ貼り師 | 一般保護フィルム貼り師 | 砂粒コレクター |

- 気泡抜きの段階は、気泡抜きの品質を100倍し、点数の軸と同じ境目（80以上＝高、40以上＝中）で決める（B-6）。気泡抜きの前に時間切れになったときは品質 0（低）として扱う。
- 落下したときは、貼り方と気泡抜きの言葉を付けず、最後の名詞を「フィルムデストロイヤー」にする。画面の綺麗さはその前に「ピッカピカの／それなりの／砂粒まみれの」で付ける（例: 早業！基板さえも磨く砂粒まみれのフィルムデストロイヤー）。
- 手早さ・画面の綺麗さ・フィルムの貼り方・気泡抜きがすべて高で、やらかしがないときだけ、つなげずに「保護フィルムに愛されし保護フィルム貼り師」にする。
- 例: 高・低・中・中（手早さ・画面・貼り方・気泡抜き）、研磨しすぎ・斜め貼りあり → 早業！斜め貼りの申し子！基板さえも磨く砂粒コレクター

### 埃が残ったときの単独の称号（R-13）

「貼り始める」を押したときに画面に残っている（着地済みの）埃が 50個以上（調整値 `DUST_TITLE_MIN`）なら、つなげた称号の代わりに単独の称号を出す。手早さ・貼り方・気泡抜き・研磨しすぎなどの言葉とはつなげない。落下・研磨しすぎ・斜め貼りがあっても、こちらを優先する。埃取りの途中で時間切れになったとき（押していないとき）はつけない。画面の埃の表示（D-7 の5段階）は変えない。

| 称号 | ひとこと（判定キー「砂粒」） |
|---|---|
| フィルム代わりの砂粒コーティング、自然由来のフィルム貼り師 | 砂粒で画面を守ることにしました |

シェア文の称号もこの称号になる（シェア文にひとことは入れない）。

## テスト・受け入れ条件

- 5工程が順に進み、制限時間内に最後まで操作できる。
- 拭き、埃取り、位置調整、4隅の仮固定、気泡抜きをタッチ操作で行える。
- 仮固定の重大な失敗でフィルムを落とすと、残りの工程が自動で進んで結果画面に「落下」が出る。その他の操作ミスは品質へ反映される。
- 評価軸の段階（高・中・低の境目 40点・80点）とやらかしの組み合わせから、つなげ方どおりに称号が作られ、優先順位どおりに38種類のひとことが正しく割り当てられる。
- 制限時間切れと工程完了の両方で結果画面が表示され、点数の軸・やらかし・称号を入れたシェア文を作成できる。
- スマートフォンの狭い画面とPC画面の両方で、主要な操作部品が画面内に収まり、タッチ／マウス操作ができる。

## 前提

- 「1〜2分」の初期設定は90秒とする。
- 仮固定では4隅それぞれにタイミング判定を設ける。
- 見た目と操作の細部は、ポップ調の試作を基準に調整する。
