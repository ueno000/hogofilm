# 保護フィルム貼りゲーム 企画・実装計画

## 概要

スマートフォンでURLを開いてすぐ遊べる、明るくポップな保護フィルム貼りゲームを作る。1プレイは約90秒を目安とし、結果は「点数の軸3つ」と「事件の軸2つ」で評価する（詳しくは「評価」）。

## ゲームの流れ

操作を次の5工程に分ける。

1. **ウェットシートで拭く** — 画面上をドラッグして拭き取る。汚れは場所によって1〜3段あり、しつこい汚れは何度かこすらないと落ちない。汚れが落ちた場所をさらに何度もこすると画面が削れ、基板（緑の地に回路の線）が見えてしまう。削れた分は仕上がり品質から差し引く。自動では次の工程へ進まず、止めどきはプレイヤーが「次へ」で決める。
2. **埃を取る** — 埃をタップして取り除く。最初にいくつか置かれたあと、埃は上から1個ずつ降り続け、間隔はだんだん短くなるので取り切ることはできない。自動では次の工程へ進まず、画面の埃が0個になった瞬間（「今だ！」と出る）を見極めて「貼り始める」を押す。品質は押した瞬間に残っている埃の数で決まる。
3. **位置を合わせる** — 方向ボタン（PC は矢印キー）でフィルムを動かす。短くタップすると少しだけ動き、長押しすると少し待ってから動き出して、押している間だんだん速くなる。開始時のずれは半端な量なので、押す回数を数えるだけでは合わせられない。フィルムは対角の2つの角を手で持っている絵になっていて、手が震え、汗をかいて緊張している。フィルムは手ごと小さく揺れるが、見た目だけで判定には使わない。ずれの表示や「ぴったり」の演出はなく、合っているかは結果画面で初めて分かる。品質は「決定」を押したときの本当の位置（揺れを含まない）のずれで決まる。
4. **仮固定する** — タイミングを見て4隅を順にタップする。
5. **気泡を抜く** — フィルム上をドラッグして気泡を押し出す。

仮固定で4隅の判定に大きく失敗すると、保護フィルムを床に落とす。ゲームは終わらず、残りの工程はフィルムがないまま操作なしで自動で進み（1工程あたり約1秒）、結果画面へ移る。このとき事件「落下」がつく。その他のミスは仕上がり品質に反映する。

## 技術スタック

- **Vite＋TypeScript**で開発し、静的サイトとしてビルドする。
- **SVG／HTML／CSS**でゲーム画面と演出を描画する。操作はPointer Eventsで実装し、タッチとマウスに対応する。
- ゲーム操作領域には`touch-action`を設定し、ドラッグ中にブラウザのスクロールや拡大操作が干渉しないようにする。
- 初版ではReact、ゲームエンジン、物理演算ライブラリ、音声ライブラリを追加しない。効果音も初版の対象外とする。
- スマートフォンはタッチ操作、PCはマウスとキーボード操作に対応する。
- 公開先は未定とし、初版はローカルで動く試作品を対象にする。公開時に静的ホスティング先を選び、共有URLとOG表示を設定する。

## 画面とシェア

- タイトル、遊び方、工程表示、結果画面を用意する。
- 結果画面に点数の軸3つ（段階つき）・ついた事件・称号とひとことを表示する。総合の品質スコアは出さない。
  - 見出しは「貼り付け完了！」。フィルムを落としたまま最後まで進んだときは「フィルムなしで完走…」、時間切れのときは「時間切れ！」（落下より優先）。
  - 残り時間は独立した行にせず、手早さの点数の根拠として手早さの横に小さく添える。
- 点数の軸3つ・ついた事件・称号を入れた投稿文を作成し、Xの投稿画面を開けるようにする。

## 評価

仕上がりを1つの点数にまとめず、軸ごとに評価する。点数の軸は「高（80点以上）／中（40点以上）／低」の3段階に分け、称号の判定に使う。具体的な数値は企画管理シートの評価設計タブを正とする。

| 評価軸 | 種類 | 決まり方 |
|---|---|---|
| 手早さ | 0〜100点 | 残り時間が多いほど高い（一定以上残せば満点）。時間切れ・落下のときは 0 点 |
| 画面の綺麗さ | 0〜100点 | 拭く工程と埃取り工程の仕上がり（拭く工程の削れは減点に含む） |
| フィルムの貼り方 | 0〜100点 | 位置合わせ・仮固定・気泡抜きの仕上がり。落下があれば 0 点 |
| 落下 | あり／なし | 仮固定でフィルムを床に落とした |
| 研磨しすぎ | あり／なし | 拭く工程で、基板が見える場所が規定の割合を超えた。工程の中では表示しない |

## テスト・受け入れ条件

- 5工程が順に進み、制限時間内に最後まで操作できる。
- 拭き、埃取り、位置調整、4隅の仮固定、気泡抜きをタッチ操作で行える。
- 仮固定の重大な失敗でフィルムを落とすと、残りの工程が自動で進んで結果画面に「落下」が出る。その他の操作ミスは品質へ反映される。
- 評価軸の段階（高・中・低の境目 40点・80点）と事件の組み合わせから、優先順位どおりに34種類の称号とひとことが正しく割り当てられる。
- 制限時間切れと工程完了の両方で結果画面が表示され、点数の軸・事件・称号を入れたシェア文を作成できる。
- スマートフォンの狭い画面とPC画面の両方で、主要な操作部品が画面内に収まり、タッチ／マウス操作ができる。

## 前提

- 「1〜2分」の初期設定は90秒とする。
- 仮固定では4隅それぞれにタイミング判定を設ける。
- 見た目と操作の細部は、ポップ調の試作を基準に調整する。
